# 📚 NoteVault

A secure semester-wise notes sharing platform for BTech CSE students.

## ✨ Features

- 🔐 Google Authentication
- 📖 Semester-wise Notes
- 💳 Subscription-based Access
- ⏳ 3-Month Access Validity
- 👨‍💼 Admin Dashboard
- 📤 Upload Notes
- ✏️ Edit Notes
- 🗑️ Delete Notes
- 🔒 Secure PDF Access using Signed URLs
- ☁️ Supabase Storage
- 📱 Responsive UI

---

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
